Privacy Policy

Effective date: September 12, 2026

Koller is an offline-first dance battle event management app for hosts, judges, MCs, presenters, and spectators.

Data Collection

Koller does not collect personal data on external servers. The app does not use advertising tracking, analytics SDKs, or a cloud backend for event data.

Local Event Data

Event data such as participant names, judge names, scores, votes, brackets, event settings, and event state is stored locally on the user's device.

Local Network Use

When users connect devices during an event, event data may be shared between those devices over the same local network. This is used to support judging, hosting, presenting, and spectator views during a dance battle.

Camera Use

Koller may request camera access to scan event connection QR codes. Camera access is used only for this purpose.

Imported Files

Koller may allow users to import participant lists from files. Imported files are processed on the device for participant management and are not uploaded to external servers by Koller.

Data Sharing

Koller does not sell, rent, or share user data with advertisers or third-party analytics providers. Event data may be shared only between devices connected to the same local event network as part of the app's core functionality.

Data Deletion

Users can delete local event data from within the app where available. Users can also remove app data by deleting the app from their device.

Children's Privacy

Koller is not designed to knowingly collect personal information from children. Since Koller does not operate a cloud backend, event data remains local to the user's device and connected local event devices.

Changes to This Policy

This Privacy Policy may be updated from time to time. Any changes will be reflected by updating the effective date on this page.
