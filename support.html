Common Setup Notes

Koller is designed to work without a cloud backend. One device acts as the host, and other devices can connect over the same local Wi-Fi network.

If another device cannot connect, make sure all devices are on the same Wi-Fi network and that local network permission is enabled for Koller in iOS Settings.

Camera Access

Koller may use the camera to scan event connection QR codes. If QR scanning does not work, check that camera permission is enabled for Koller in iOS Settings.

Local Event Data

Event data is stored locally on the device. If you delete the app, local event data may also be removed from the device.
